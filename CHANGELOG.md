# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-09-07

### Added

- Meta `products` checkout URL parsing.
- Product, variation, SKU, and prefixed-ID resolution.
- Custom catalog-ID mapping filter.
- Optional WooCommerce coupon handling.
- Cart replacement behavior for Meta checkout sessions.
- Attribution parameter preservation.
- Input limits and redirect-loop protection.
- Public documentation and GPL-2.0-or-later licensing.
